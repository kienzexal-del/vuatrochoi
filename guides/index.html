Windows

  1. Lấy key đã mua

    Đăng nhập tài khoản Google đã mua hàng, mở Đơn hàng của tôi và sao chép key Vua Trò Chơi.

  2. Mở cửa sổ lệnh

    Bấm Start, tìm Windows PowerShell, chọn Run as administrator rồi xác nhận quyền quản trị.

  3. Sao chép và chạy lệnh

    irm tinyurl.com/vtch-win | iex

    Dán lệnh bằng Ctrl + V hoặc chuột phải, sau đó nhấn Enter.

  4. Nhập key vừa mua

    Khi hệ thống hỏi key bản quyền, dán key vừa mua rồi nhấn Enter. Mật khẩu máy dùng cho sudo và key bản quyền là hai thông tin khác nhau.

  5. Mở lại Steam

    Chờ thông báo cài đặt/kích hoạt thành công, sau đó đóng và mở lại Steam. Nếu có lỗi, chụp thông báo gửi hỗ trợ.

macOS

  1. Lấy key đã mua

    Đăng nhập tài khoản Google đã mua hàng, mở Đơn hàng của tôi và sao chép key Vua Trò Chơi.

  2. Mở cửa sổ lệnh

    Nhấn Command + Space, tìm Terminal rồi mở ứng dụng.

  3. Sao chép và chạy lệnh

    curl -fsSL https://raw.githubusercontent.com/kienzexal-del/vuatrochoi/main/install_mac.sh -o /tmp/vtch-install-mac.sh && sudo bash /tmp/vtch-install-mac.sh

    Nếu hỏi Password, nhập mật khẩu máy Mac rồi nhấn Enter. Terminal không hiện ký tự khi gõ mật khẩu.

  4. Nhập key vừa mua

    Khi hệ thống hỏi key bản quyền, dán key vừa mua rồi nhấn Enter. Mật khẩu máy dùng cho sudo và key bản quyền là hai thông tin khác nhau.

  5. Mở lại Steam

    Chờ thông báo cài đặt/kích hoạt thành công, sau đó đóng và mở lại Steam. Nếu có lỗi, chụp thông báo gửi hỗ trợ.

  4. Nhập key vừa mua

    Khi hệ thống hỏi key bản quyền, dán key vừa mua rồi nhấn Enter. Mật khẩu máy dùng cho sudo và key bản quyền là hai thông tin khác nhau.
